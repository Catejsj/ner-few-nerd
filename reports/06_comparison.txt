[1] HOW WE ARE SCORING
    Level          entity, not token
    Matching       EXACT - type, start token and end token must all match
    A span that overlaps a gold entity but starts one token early counts
    as a false positive AND leaves the gold entity as a false negative.
    It is punished twice. That is the CoNLL convention and the strictest
    reasonable reading; [4] separates those near-misses out so the
    penalty is visible rather than hidden.

    test sentences 37,648, gold entities 96,842

    Best micro F1: CRF at 0.650.
    The intervals are narrow because the test set is large, so these
    differences are real rather than noise.

    micro averages over entities, so it is dominated by location, person
    and organization, which are 69% of the test entities. macro averages
    over the 8 types equally, so a model that ignores the rare types is
    punished. We report both because they answer different questions:
    micro is 'how often is this system right', macro is 'does it work
    for every type'.

[6] WHERE THE APPROACHES DISAGREE
    Entities found by exactly one approach - what each one uniquely adds.
    Gazetteer              finds  46,187 correctly,  8,648 of which no other approach finds
    CRF                    finds  61,490 correctly, 15,026 of which no other approach finds
    spaCy (pre-trained)    finds  37,789 correctly,  2,784 of which no other approach finds
    ANY of the three       finds  75,496 (78.0% of all gold entities)
    ALL three agree on      20,932 (21.6%)

    A perfect combination of the three would reach 78.0% recall, against
    63.5% for the best single approach. That gap is the argument for an ensemble,
    and it is listed under future work.
